# mockserver

本地测试用的假二手书站，纯 Go 标准库，没有任何第三方依赖。

## 跑起来

```
go run ./mockserver
```

默认监听 18080，想换端口就 go run ./mockserver -addr :9090。起来之后开 http://127.0.0.1:18080 能看到个首页。

## 接口

- `GET /api/books?page=1` 列表，一页固定 20 本，返回 total / page / page_size / total_pages / items
- `GET /api/books/{id}` 详情，比列表多 stock、成色、isbn、上架日期、描述
- 页码从 1 开始，翻超了返回空 items，不报错

注意：这站有限流，全站每秒最多 10 个请求，超了就回 429，响应里带 Retry-After。

## 数据

- 固定种子生成的 3000 本假书，不重新生成的话每次启动都一模一样
- `go run ./mockserver -regenerate` 会重新生成一份数据集：价格库存会变，偶尔下架几本，改动写到 data.json，跑完就退出不起服务，重新生成完把服务重启一下就是新数据
- 平时启动都优先读 data.json，删掉这个文件就回到最初的 3000 本，数据文件默认在当前目录下，想换地方用 -data
- 下架的书在列表里看不到，详情也是 404，但并没有真正删掉

书的数据我没洗过：标题分类可能带前后空格（全角空格也有），价格是字符串，描述里混着 html 标签，要用的话自己处理一下。
